   - 렌더러 무수정. eyebrow·문서 본문에는 한국어 학년만 쓰면 교사 눈에는 병기가 안 보인다 (grade는 meta로만 쓰임 — 단, 렌더 확인 필요: Task 7에서 meta 줄 노출 여부 실측).

3. **계획 대비 편차.** check_docx.py의 needle "성취기준"은 JSON 콘텐츠에 없는 단어였다(성취기준 콜아웃 라벨은 렌더러가 영어로 조립 — 위 1번). needle을 standard_text 실제 구절("과학적으로 탐구할 수 있다")로 교체.

## 번외 — kordoc HWPX 시험 생성 (2026-08-01)

ADR-4 재검토 조건("마크다운 경유에서 표·수식 손실 확인 시")을 실측하려고 파일럿 6종을
kordoc MCP로 HWPX 생성했다. **3단계 어댑터 구현이 아니라 경로 타당성 확인이다** — 산출물은
`pilot/*/out/*.hwpx`, docx는 그대로 둔다.

경로: `parse_document`(docx → md) → 헤딩·콜아웃 수동 정비 → `generate_document`(프리셋 미지정
범용 모드, `font: gothic`) → `render_document`로 PNG 육안 검증. 6종 전부 생성·렌더 통과,
한글 깨짐 0건, 표 20개 전부 보존(중등 4+2+4, 초등 3+3+4).

**3단계 어댑터 설계에 넘길 실측 3건:**

1. **표 셀 `<br>`가 줄바꿈으로 작동한다 — 답란 높이 확보 수단.** 마크다운 표는 셀 높이를
   지정할 수 없어 빈 답란이 1줄로 찌그러지는 것이 이 경로의 최대 약점이었는데, 전각 공백 +
   `<br>` 반복으로 원하는 줄 수만큼 확장된다. 중등 설계표 3줄, 초등 관찰표 5줄로 검증.
2. **단일 컬럼 표 = 그리기 박스 대용.** 초등 학습지의 그림 칸(원본 docx의 answer_box)을
   `| 내 그림 |` 1열 표 + `<br>` 12개로 재현. 렌더에서 실제 그리기 공간이 나온다.
3. **손실 1건: 렌더러의 학년 밴드 프로필이 넘어오지 않는다.** answer_box 고정 높이
   (초3–5 150pt / 중 130pt)는 md에 표현할 수 없어 `<br>` 개수로 수동 근사했다. 3단계
   어댑터는 lesson.json → md 변환 시 이 매핑(밴드 → `<br>` 개수)을 코드로 들고 있어야 한다.

**미실측 1건(정직 기록):** 원본 docx의 `📌`·`✋` 이모지는 HWPX 폰트에서 깨질 것을 우려해

## Task 3 노트 정정 — 학년 밴드 감지

Task 3에서 `"초4 (Grade 4)"` 형태로 병기하면 감지된다고 적었으나 **틀렸다.**
`grade_number()`는 `shared.grade`에서 **첫 번째 숫자**를 취한다(`re.search(r"\d{1,2}", s)`).
`"중학교 2학년 (Grade 8)"` → 2로 읽혀 초1–2 밴드(답란 200pt)로 강등됐다.

**확정 규칙: 영문 학년을 앞에 쓴다** — `"Grade 8 · 중학교 2학년"`, `"Grade 4 · 초등학교 4학년"`,
`"Grade 10 · 고등학교 1학년"`. 검증: 중 → 8 → 130pt/줄노트 없음, 초4 → 4 → 150pt/줄노트.
`shared.grade`는 산출물에 출력되지 않음을 확인(교사 눈에 안 보임). science.md 매핑 절에 명문화.
