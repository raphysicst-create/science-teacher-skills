# 원본 대조 실험 — 같은 요청, 원본 스킬 vs 포팅판 (2026-08-01)

원본 `anthropics/k12-teacher-skills` v0.6.0을 플러그인으로 실제 설치하고, 파일럿 #1·#2와
**동일한 교사 요청**을 원본 스킬로 실행해 산출물을 대조한 기록.

## 실험 조건

| 항목 | 값 |
|---|---|
| 원본 설치 | `claude plugin marketplace add <clone>/plugin` → `claude plugin install k12-teacher-skills@k12-teacher-skills` |
| 원본 인벤토리 | 스킬 2종(lesson-planning, lesson-differentiation), MCP 9종(ASSISTments·Brisk·Canva·Coteach·Diffit·Eedi·MagicSchool·Snorkl·TeachFX), 상시 ~730 tok |

| 요청 B | "초4 과학, 물의 상태 변화 중 증발과 응결 관찰 40분 수업 만들어 줘" |

## 확인된 사실

### 1. 원본은 한국 요청에도 NGSS를 조용히 적용한다

원본 `science.md`: *"Defaults applied silently: **NGSS**, 45–60 min, universal access design."*
비-미국 관할을 위한 분기가 없다. "중2"는 원본의 주(state) 감지기(TEKS/SOL/CA-NGSS…)에
걸리지 않으므로 no-op으로 지나가고 NGSS 기본값이 그대로 선다. 결과적으로 한국 교사가
행정적 효력이 없는 미국 성취기준을 받는다.

요청 B에서는 더 심하게 어긋난다 — NGSS 4학년에는 증발·응결 항목이 아예 없어서
원본 실행은 **5학년 기준(5-PS1-1)으로 학년을 이탈**해야 했다. 한국 교육과정에서는
초4 정위치 주제다.

### 2. 원본에는 출력 언어 지시가 없고, 유일한 언어 규칙이 반대 방향을 가리킨다

SKILL.md: *"Say 'home language,' not a specific language, and print translations only into a
language the teacher has named."* 교사가 한국어로 **썼지만** 한국어를 **명명하지는** 않았으므로,
문자 그대로 읽으면 한국어 출력이 막힌다. 두 실행 모두 한글 0자의 영어 문서 3종을 냈다.

원본은 영어가 교실 언어이고 한국어는 다중언어 학습자용 보조 언어라는 모델을 전제한다.
이 지점이 포팅에서 가장 큰 단일 격차였고, ADR-6의 "교사 대면 문구 전부 한국어화"가
대응한다.

### 3. 원본 학년군 단계별 분(分)은 한국 차시에 물리적으로 안 맞는다

- 6–8 밴드 최소합: 5+20+15+10+5+5 = **60분**. 한국 중학교는 **항상 45분**.
- 3–5 밴드 최소합: 5+15+10+10+5+3 = **48분**. 한국 초등은 **40분**.

두 실행 모두 SKILL.md의 하드 규칙(*"the phases sum to exactly the stated period"*)을 지키려고
여러 단계를 원본이 명시한 최소치 **아래로** 깎았다(요청 A는 6단계 중 3개, 요청 B는 4개).
원본 자체 기본값이 "45–60 min"인데 그 하한조차 자기 구조로 불가능하다.

→ 포팅판이 `science.md`에 45분 실배분 예시와 "탐구 활동·논증 토의를 지키고 나머지를 줄인다"
규정을 넣은 것이 이 충돌의 직접 대응이다. Task 7에서 파일럿 중 발견해 추가한 항목.

### 4. 렌더러 학년 파싱 — 포팅판 우회 규칙이 실측으로 확인됨

`lesson_common.py:552`의 `re.search(r"\d{1,2}", s)`는 `shared.grade`의 **첫 숫자**를 취한다.

```
'Grade 8'                 -> 8   (원본은 자연히 통과)
'중학교 2학년'             -> 2   ← 초1–2 밴드로 강등, 답란 200pt
'Grade 8 · 중학교 2학년'   -> 8   ← 포팅판 확정 규칙
'초등학교 4학년'           -> 4   (우연히 맞음)
'Grade 4 · 초등학교 4학년' -> 4
```

원본은 애초에 영어 학년 문자열을 쓰므로 이 버그를 만나지 않는다. 한국어 학년 표기를
쓰는 순간 드러나는 이식 고유 결함이고, 렌더러 무수정 원칙 때문에 JSON 쪽 규약으로 우회했다.
`중학교 2학년`은 깨지고 `초등학교 4학년`은 우연히 통과하므로 **초등만 테스트했다면 놓쳤을**
버그다.

### 5. 죽은 분기 — 원본에서 실행되지 않는 기제

| 원본 기제 | 한국에서의 상태 |
|---|---|
| 주(state) 감지, `jurisdiction` 전달 | no-op. "중2"는 주 신호가 아님. clarify 우선순위 4는 한국 교사에게 "어느 주에서 가르치세요?"를 묻게 만듦 |
| OpenSciEd 분기 (커리큘럼 1:1 = OSE→science) | 완전 사문. 실제 쟁점(검정 교과서 출판사·실험관찰)은 물을 수단이 없음 |
| 저작권 가드레일 (IM·OpenSciEd 명명 금지) | 실제 노출원인 검정 교과서·지도서를 보호하지 않음 |
| "Headings use sentence case" | 한국어에 대소문자 없음 — 규칙이 무의미 |
| 정리 문항 3분류 (Got it / Almost there / Needs re-teaching) | 성취수준 A–E·상중하 기록 체계와 대응 없음 |
| 단원 위치 추측 금지 규정 | **한국에서는 반대로 틀림** — 국가 단일 교육과정이라 위치가 실제로 확정적인데, 원본 규정이 그 정보를 버리게 함 |

### 6. 원본이 그대로 잘 도는 부분

- **렌더 파이프라인**: 두 실행 모두 스크립트 오류 0, 첫 시도에 docx/html 3종 생성. 포팅판이
  렌더러를 무수정으로 둔 결정(ADR-6)이 실측으로 지지된다.
- **구조 규율**: 단계 합 = 차시 분, 준비물과 단계 일치, 목표 3슬롯 분리 진술, faceted
  teacher/student 블록 — 전부 언어 중립이고 포팅판이 그대로 계승한 뼈대다.
- **미연결 처리**: 원본 규정대로 KG 인용을 지어내지 않고 지정 푸터를 정확히 삽입했다.

## 부수 발견

- 원본 실행이 마찰 로그에서 한국 성취기준을 훈련 지식으로 추정하며 `[4과08-02]`/`[4과08-03]`을
  댔는데, MCP로 확인한 실제 코드는 `[4과10-02]`다. **학습맵 MCP 연결의 가치를 보여주는
  직접 사례** — 코드 추정은 그럴듯하지만 틀린다.
- 스키마 내부 모순 1건(원본·포팅판 공통): SKILL.md 형식 스키마는 `fill_table`에
  `blank_rows: int`만 두는데 "Which block when" 표는 `rows`를 리스트로도 받는다고 적는다.
  두 실행에서 양쪽 형태 모두 렌더는 성공.
- 렌더러 영어 크롬(`Target standard`, `Students see:`)은 원본 실행에서는 당연히 문제가 없다.
  한국어 문서에서만 드러나는 이식 이슈이고, 3단계(렌더러를 어차피 만지는 단계) 결정 대상으로
  남아 있다.

## 실험 후 정리

원본 플러그인은 설치된 상태로 남아 있다(`k12-teacher-skills@k12-teacher-skills`, user scope).
마켓플레이스 소스가 스크래치패드 clone을 가리키므로 세션 임시 폴더가 지워지면 갱신이 깨진다.
계속 참조하려면 durable 경로로 다시 clone해 `claude plugin marketplace add`를 재실행하고,
필요 없으면 `claude plugin marketplace remove k12-teacher-skills`로 제거한다.
