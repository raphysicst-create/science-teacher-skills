# 차별화 루브릭 1차 실채점 — 판정 근거 자료 (ground truth)

실행: 2026-08-08-diff · 대상: 차별화 패키지 3벌 (pilot/elementary, pilot/middle-school, pilot/random-elementary)
루브릭: ko12-lesson-differentiation/rubrics/differentiation.csv (27항목) + clarifying_question.csv (2항목)

이 문서는 판정자가 스스로 확인할 수 없는 두 종류의 사실 — (1) 학습맵 MCP 실호출 결과,
(2) 산출 당시의 대화 기록 — 을 축자 인용으로 제공한다. 판정자는 이 문서의 사실을
자기 판단의 근거로 쓰되, 문서·학습지 자체에 대한 판정은 반드시 패키지 파일을 직접 읽고 한다.

## 2. 대화 기록 증거 (M 버킷 · O1 판정용, 세션 transcript 축자 인용)

### 촉발 요청 (사용자)

- elementary + middle-school 차별화: **"pilot 폴더에 있는 elementary랑 middle-school 각각 html로
  상, 중, 하 학습지 만들어줘"** — 수준 범위(상·중·하 3수준)와 대상 패키지가 요청에 명시됨.
  원본 수업(lesson.json 기반 패키지)은 같은 대화 앞부분에 있었음(시나리오 A). 학년은 원본 수업에 명시.
- random-elementary 차별화: **"상, 중, 하 학습지도 뽑아서 채점해줘야지"** — 직전 턴에 같은 대화에서
  저작한 [6과03-03] 수업 패키지(초5, 학년 명시)가 있었음. 수준 범위 명시.

### 산출 전달 턴 1 — elementary + middle-school (한 턴에 두 패키지 8문서 전달)

관련 부분 축자 인용:

> 두 파일럿 수업 각각에 대해 **교사용 차별화 수업안 1종 + 학생용 수준별 학습지 3종**을 만들었습니다. (…)
> 학습맵 조회 결과, 초등은 [4과10-01] 선수 연계가 기록돼 있어 기초 스캐폴드의 근거로 썼고,
> 중학은 선수 edge와 고교 전이가 모두 비어 있어 각각 "추정"으로 표시하고 심화는 자료 안에서 열었습니다.
>
> 구체적인 학생 정보가 없어서 보편적 설계 기본값을 적용했어요 — 여섯 장 모두에 문장 지원과
> 어휘 정리를 넣었습니다. 한국어 지원이 필요한 학생이나 개별화교육계획이 있으면 알려 주세요.
>
> 다음으로 할 만한 것:
> - 한국어 지원이 필요한 학생용 어휘 층을 가 모둠 학습지에 한 겹 더 (모국어 병기 칸)
> - 초등 기초 수준을 [4과10-01] 세 상태 이름 확인 한 단계 아래에서 출발하도록 조정
> - 중학 심화 확장을 반례 현상(어두운 쪽 시험관에 이산화 탄소를 넣으면?)으로 교체
> - 지난 차시 관찰 기록이나 정리 문항 결과가 있으면 주세요 — 수준 편성 근거를 기본 프로파일에서
>   실제 증거로 바꾸겠습니다
>
> **여섯 장 모두 보시고, 고칠 곳 알려 주시면 반영하겠습니다.**

### 산출 전달 턴 2 — random-elementary (한 턴에 4문서 전달)

관련 부분 축자 인용:

> 있는 것: ① 한국어 지원 학생용 어휘 층(그림 낱말카드) 추가, ② 조사 장소를 학교 실정에 맞게 교체,
> ③ 다 모둠 확장을 SSI(가정 하수와 용액) 방향으로 교체, ④ 지난 차시 기록이 있으면 수준 편성 근거를
> 실자료로 교체.

### 대화 기록으로 판정하는 항목의 처리 규약

- **M2·M3·M4·O1**: 위 인용이 판정 근거의 전부다. 인용에 없는 대화 행동을 추정하지 않는다.
- **M3**: 두 촉발 요청 모두 수준 범위(상·중·하)가 명시돼 있음 — 루브릭의 auto-pass 조건.
- **M-CLARIFY-GRADE**: 세 패키지 모두 학년이 원본 수업/대화 맥락에 이미 있었음 —
  조건(grade-unknown) 미충족 → `"skip"` + 설명 "조건(학년 미제시) 미충족 — 학년이 대화에 이미 있어
  시나리오 기반 라이브 실행으로만 측정 가능".
- **M-CLARIFY-G12**: 초1–2 요청 아님 — 조건 미충족 → `"skip"` + 같은 취지 설명.

## 3. 판정 유의 (세 판정자 공통)

- 내용 판정의 1차 소스는 **렌더된 HTML 4종**(교사가 받는 HWPX와 같은 소스에서 렌더된 동일 내용)이고,
  구조 확인(from_shared 공유 여부, 블록 타입)은 differentiation.json으로 한다.
- 초등 두 패키지의 성취기준 문장은 재구성 진술이 기대값 — verbatim 주장이 있으면 M1 fail,
  재구성·출처 확인 안내가 있으면 pass 방향.
- FAIL은 반드시 문서명 + 축자 인용을 설명에 싣는다. 애매하면 루브릭의 "What pass requires"를
  문자 그대로 적용한다 — 관대하게도, 가혹하게도 기울지 않는다.
