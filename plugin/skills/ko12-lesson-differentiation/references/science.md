# 과학 — 차별화 pedagogy

`ko12-lesson-differentiation`이 로드하는 유일한 과목 레퍼런스.

## 원본 수업 확인

네 시나리오 — 어느 것인지 판단한다:

**시나리오 A — 이 대화 앞부분에 원본 수업이 있다**
이미 만들었거나 논의한 수업이 있으면 그대로 쓴다. 교사에게 다시 공유해 달라고 하지 않는다.

**시나리오 B — 교사가 원본 수업 파일을 올린다**
파일을 먼저 읽는다. 확인할 것: 학년·학교급, 성취기준(코드와 원문), 앵커 현상, 수업 단계
구조, 3범주 중 무엇이 전면에 나와 있는지. 첫 시도에 읽히지 않으면 오류를 분명히 말하고
다시 공유를 요청한다. 조용히 지어내지 않는다.

**시나리오 B2 — 교사가 링크로 준다**
URL을 가져와 내용을 먼저 읽고, 시나리오 B와 똑같이 확인한다. 가져오기가 실패하거나 쓸 수
없는 내용이면 분명히 말하고 붙여넣기나 파일 업로드를 요청한다.

**수업을 가져온 것으로 Step 1이 끝날 뿐, 성취기준 확인을 대신하지 않는다.** Step 2로
계속한다. URL을 읽은 뒤 Step 2를 건너뛰는 것은 업로드된 수업에서 건너뛰는 것과 같은
치명적 실패다.

**시나리오 C — 원본 수업이 없다**
진행 전에 묻는다:
> "차별화 도와드릴게요. 염두에 둔 수업이 있으신가요? 붙여넣거나 파일로 주셔도 되고,
> 학년 + 주제 + 성취기준만 알려 주셔도 그걸로 만들 수 있어요."

**교과서 확인.** 교사가 출판사·교과서를 말하면 단원의 위치 감각으로만 쓴다. 확언하지
않은 출판사명은 쓰지 않는다(SKILL.md 저작권 가드레일). 한국은 국가 교육과정 단일 체제라
성취기준은 공통이고, 달라지는 것은 교과서의 전개 순서뿐이다.

## 차별화 규칙

여덟 규칙을 모든 차별화 수업에 적용한다.

### R1 — 산출 구조

**교사용 통합 차별화 수업안 1종 + 순수 학생용 학습지 3종. 수준별 수업안 3종을 만들지
않는다.**

수업안은 교사가 원본 수업 대신(또는 함께) 쓸 수 있는 하나의 문서다. 수업 단계로
조직한다. 모든 학생이 함께하는 단계(현상 던지기, 논증 토의, 정리)는 한 번만 쓴다. 학생이
따로 활동하는 단계(탐구 활동, 설명 쓰기)는 세 수준을 한 표에 나란히 보인다.

교사 노트와 학생 과제가 섞인 문서를 3벌 만들지 않는다.

### R2 — 3범주 범위 보존

**모든 수준이 원래 성취기준을 다룬다. 지식·이해, 과정·기능, 가치·태도 셋 다 모든 수준에
나타나야 한다 — 어려운 부분까지 포함해서.**

- **지식·이해**: 같은 개념이 세 수준 모두의 내용 목표다
- **과정·기능**: 전면에 나온 탐구 기능이 모든 수준의 과제에 나타난다(수업이 "실험
  설계"를 요구하면 세 수준 모두 설계한다)
- **가치·태도**: 같은 태도 목표가 세 수준 모두에서 관찰 가능해야 한다

기초 수준의 인지적 범위를 줄이는 것 — 범주 하나를 빼거나, 탐구를 읽기 자료로 바꾸거나,
현상을 단순화하는 것 — 은 차별화가 아니다.

**기초 수준의 참여도를 보존한다.** 보통·심화에는 열린 탐구를 주고 기초에는 빈칸 채우기
학습지를 주면서 다른 학생만 과학을 하게 두지 않는다. 모든 수준이 같은 현상을 탐구한다 —
과제가 다른 게 아니라 지원이 다르다.

### R3 — 관찰 → 표현 → 설명 진행으로 끌어올리기

**기초 수준 스캐폴드는 학년 수준의 설명으로 학생을 끌어올린다 — 우회로가 아니다.**

| 수준 | 진입점 |
|---|---|
| 기초(가 모둠) | 관찰 → 표현(구조화된 지원과 함께), 그다음 문장 지원이 있는 설명으로 |
| 보통(나 모둠) | 표현 → 설명(표준 주장·증거·추론) |
| 심화(다 모둠) | 설명 → 확장(일반화, 반례 현상, 정량화, 공학적 적용) |

**기초 수준 스캐폴드는:**
- 자기 관찰에 접근하고 뜻을 붙이게 돕는다(구조화된 관찰 발문, 주석 붙인 그림)
- 관찰에서 자료 표현으로 넘어가는 발판을 준다(안내가 있는 자료 표, 일부만 채워진 모형 틀)
- 주장·증거·추론 구성을 문장 지원으로 받쳐 준다 — 설명 자체를 주지 않는다

**사고의 충돌은 양보하지 않는다.** 기초 수준 학생이라고 해서 기존 생각과 관찰 사이의
충돌을 매끄럽게 덮어 주지 않는다 — 이름 붙이게 돕는다:
*"나는 ____라고 생각했는데 ____를 보았다. 이제 나는 ____라고 생각한다."*

**개념적 선수 학습 찾기:**
학습맵의 선수관계(`get_prerequisites`)를 쓴다. 공식 선수 edge가 있으면 그것을 기초 수준
스캐폴드의 다리로 삼고 **3범주 지도**에 이름을 적는다. edge가 없으면(중등에서 흔하다)
훈련 지식으로 추정하되 **"추정"으로 표시한다** — 학습맵에 없는 관계를 단정하지 않는다.

- ✓ "기초 수준은 [선수 성취기준의 모형]에서 출발해 그 표현을 새 현상에 적용한다."
- ✗ "기초 수준은 더 쉬운 탐구를 한다."

### R4 — 기초 수준 스캐폴드

**목표는 생산적 어려움을 없애는 것이 아니라 탐구를 통과하도록 지탱하는 것이다. 탐구를
우회시키지 않는다.**

피해야 할 실패:

- ❌ 학생이 탐구하기 전에 설명을 미리 말해 주기
- ❌ 기초 수준에서 탐구를 빼고 읽기 자료나 영상으로 대체하기
- ❌ 현상을 단순화하기 — 모든 수준이 같은 현상을 본다
- ❌ 핵심어 전략: "'열'이라는 말이 나오면 에너지 이동이라는 뜻이야"
- ❌ 답이 드러나는 도움 자료
- ❌ 과학 탐구 스캐폴드 대신 읽기·쓰기 지원만 넣기

받아들일 수 있는 스캐폴드:

- ✓ **관찰 → 연결 → 의미**를 순서 짓는 안내 발문: *"무엇이 달라졌나요? 무엇이 그대로인가요?
  무엇 때문이라고 생각하나요?"*
- ✓ **주장·증거·추론 문장 지원**: *"나는 ____라고 주장한다. 내 증거는 ____이다.
  이것이 주장을 뒷받침하는 이유는 ____이다."*
- ✓ **일부만 채워진 모형 틀** — 학생이 채우는 구조, 이미 완성된 그림에 이름만 붙이는 게 아니라
- ✓ **어휘 지원** — 학습지 상단의 낱말 상자나 짧은 뜻풀이(일상어 정의 포함)
- ✓ **구조화된 관찰 기록지**(*"본 것을 그리세요. 달라진 곳에 이름을 붙이세요. 뜻밖인 것에
  동그라미 하세요."*)
- ✓ **열 이름과 단위가 미리 채워진 자료 표** — 학생은 관찰을 채우고, 해석은 스스로 한다
- ✓ **선수 학습 되살리기** — *"지난번에 ____를 알아냈지요? 그게 지금 보는 것을 설명하는 데
  어떻게 도움이 될까요?"*

#### 스캐폴드 밀도 상한

**과제당 삽입 스캐폴드는 1–2개. 넘지 않는다.**

| 유형 | 상한에 포함? |
|---|:-:|
| 삽입형 — 모든 과제에 인쇄되는 것(조직자, 문장 지원, 힌트 문구) | 예 |
| 문서 수준 기능 — 어휘 상자, 상단의 주장·증거·추론 틀 | 아니오 |
| 교사 쪽 도구 — 요청 시 주는 도움 자료, 개별 지도 발문 | 아니오 |

주 스캐폴드를 먼저 고른다. 두 번째는 진짜로 다른 방식을 더할 때만 넣는다. 같은 인지적
자리를 덮으면 뺀다.

### R5 — 필수 교수학습 장치

**모든 차별화 과학 수업에 다섯 가지가 다 있어야 한다. 수업안 안에 녹여 넣는다.**

| 요소 | 무엇인가 | 수업안의 어디에 |
|---|---|---|
| **형성 확인** | 수업 중간이나 끝의 구체적 확인 — 정리 문항이나 설명 점검. "순회하며 관찰한다"는 해당 없음 | 그 단계 안에 |
| **앵커 활동** | 먼저 끝낸 학생용 성취기준 정합 확장 과제. 시간 때우기가 아니라 전면에 나온 탐구 기능을 요구해야 한다. `shared.anchor_activity`에 학생 대면으로 쓰고 학습지 3종 모두에 인쇄한다 — 수업안 설명으로만 존재하면 실패 | 수업안 끝 + 학습지 3종 |
| **유연한 편성 문구** | 수준 배정이 이 수업의 증거에 근거하며 형성 확인에 따라 바뀔 수 있다는 진술 | 수업안 머리의 짧은 콜아웃 |
| **수준별 예상되는 학생 생각** | 수준마다 흔한 생각 + 교사의 개별 지도 발문 + 소집단이 필요한 신호 | 각 수준별 활동 블록 안 콜아웃 — 수준당 2문장 이내 |
| **사고 충돌 발문** | 기존 생각과 관찰 사이의 긴장을 드러내는 발문 | 탐구 활동이나 설명 쓰기 과제 안에 |

또한 **각 학습지는 세 수준 공통의 성찰 발문 하나로 끝난다**:
*"아직 궁금한 것은 무엇인가요?"* `shared.reflect_prompt`에 저장하고 수업안의 각 수준
**학습지 과제** 줄에 이름을 적는다 — 인쇄됐는데 수업안이 부르지 않으면 실패다.

### R6 — 보이지 않는 조정

**수준 간 같은 현상, 같은 탐구, 같은 핵심 설명 과제. 지원만 다르다.**

모든 수준이 같은 현상을 본다. 모든 수준이 같은 준비물과 절차로 탐구한다. 통합 수업안에서
공유 탐구와 현상은 "모든 학생" 아래 한 번만 나온다. 수준 블록은 **다른 것만** 보인다 —
스캐폴드, 개별 지도 발문, 확장.

전체 탐구 내용을 수준 블록마다 다시 쓰지 않는다 — 참조하고 차이만 기술한다.

**스캐폴드가 빠지는 것을 학생에게 알리지 않는다.** 과제 1에 관찰 기록지를 쓰고 과제 3에
쓰지 않는다면 그 부재는 조용하다 — 라벨도, 곁말도, 언급도 없다("이번에는 틀 없이"
같은 말 금지). 스캐폴드는 그냥 나타나지 않고, 학생은 과제를 그 자체로 만난다.

숫자·자료·준비물 수량은 기본적으로 수준 간 동일하다. 탐구 구조가 온전히 보존되는
경우에만 기초 수준에서 조정할 수 있다.

### R7 — 수준 내 점진적 스캐폴딩

**각 수준의 학습지는 과제를 인지적 요구가 커지는 순서로 배열한다.**

#### 기초 수준 제거 방식

| 과제 | 삽입 스캐폴드 | 방식 |
|---|:-:|---|
| 관찰 과제 | 최대 2 | 구조화 |
| 표현 과제 | 최대 1 | 안내 |
| 설명 과제 | 0–1 (문서 상단의 틀은 허용) | 생산적 어려움 |
| 성찰 발문 | 0 | 스스로 |

#### 심화 수준 확장 품질 검사

모든 심화 확장은 이 질문에 답해야 한다: **보통 수준 학생이 이미 하고 있지 않은 어떤 새
사고를 요구하는가?**

진짜 확장은 다음 중 최소 하나를 요구한다:
- **공학적 적용**: 그 과학 개념으로 해결책을 설계한다
- **반례 현상**: 현상이 다르게 행동하는 상황 — 일반화를 요구한다
- **정량화**: 정성적 설명을 수치 관계로 잇는다
- **다음 성취기준 예고**: 같은 영역의 다음 성취기준 — 어휘가 아니라 개념 요소로
- **과학적 논증**: 경쟁하는 설명을 평가하거나, 자기 주장을 반박할 증거를 찾거나, 반론을 쓴다
- **과학-사회 연결(SSI)**: 이 현상이 실제 문제나 의사결정과 어떻게 이어지는가 (중·고)

거절할 것: 같은 탐구를 더 많이, 더 긴 학습지, 표기만 바꾼 것.

### R8 — 범위와 기본값

**수준 범위가 지정되지 않았으면 생성 전에 하나로 묶어 묻는다:**

> "기초 / 보통 / 심화 세 수준으로 나눌게요 — 이 셋이 맞을까요? 그리고 알아 둘 학생
> 정보가 있을까요(한국어 지원이 필요한 학생, 개별화교육 목표 등)? 없으면 보편적 설계
> 기본값(세 수준 모두 문장 지원과 어휘 지원)으로 진행합니다."

범위가 이미 지정됐으면 기본값을 조용히 적용하고 진행한다.

**지정되지 않았을 때 조용히 적용하는 기본값:**
- 수준: 기초 / 보통 / 심화 (학생 문서에서는 가 / 나 / 다 모둠)
- 보편적 설계: 주장·증거·추론 문장 지원과 어휘 정리를 **학습지 3종 모두**에(기초에만이 아니라)
- 범위: 수업 전체(모든 단계 + 정리 문항)

**형성평가 자료가 없을 때**는 이 기초 수준 프로파일을 기본으로 한다:
- 현상을 관찰할 수는 있으나 기제를 아직 이름 붙이지 못한다 — 지각적 접근은 되고 설명
  언어가 없다
- 이 개념에서 흔한 생각을 최소 하나 갖고 있을 가능성이 높다. 사고 충돌 문장
  (*"나는 ____라고 생각했는데 ____를 보았다"*)이 주 스캐폴드다
- 관찰은 만들어 내지만 그것을 모형이나 설명으로 잇는 데 구조가 필요하다
- 근접한 선수 개념이 단단하지 않을 수 있다

기초 수준 스캐폴딩을 이에 맞춰 설계한다: 구조화된 관찰 발문 → 생각을 드러내는 문장
지원 → 주장·증거·추론 틀. 설명 내용을 미리 받쳐 주지 않는다.

추정된 결손이 한 단계보다 넓으면 **다음 단계** 블록에 수업 수준의 차별화를 넘어선 지원이
필요할 수 있다는 표시를 남긴다.

기본 수준별 수업안을 만든 뒤 교사에게 청한다: *"지난 차시 기록이 있으신가요 — 관찰
기록, 학생 설명 글, 정리 문항 결과 같은 것이요. 어떤 생각이 실제로 살아 있는지, 학생들이
관찰은 되는데 설명에서 막히는지 알 수 있으면 스캐폴드의 초점을 옮길 수 있어요."*
형성평가 자료가 과학에서 기본 접근을 뒤집는 일은 드물지만 초점을 분명히 해 준다.

### 문서 내용 — 학습지 (`id: worksheet_group_a` / `worksheet_group_b` / `worksheet_group_c`)

학습지에는 교사 노트·관찰 지점·설계 근거가 없다. 어휘, 문장 지원, "먼저 끝냈다면" 앵커
과제, 성찰 발문은 `shared`에서 끌어오므로 세 수준에서 구조적으로 동일하다.

인쇄된 지면에서는 "CER"이나 "사고 점검" 같은 말을 쓰지 않는다 — 교사의 말이다
(SKILL.md의 학생 대면 언어). 조직자 이름은 *주장 / 증거 / 추론*으로 풀어 쓰고, 사고
충돌 틀은 *"생각을 확인해 보기"*로 소개한다.

|---|---|
| 기초(가) | 보통과 같은 현상·같은 탐구. R4에 따른 스캐폴드를 R7 제거 방식으로 삽입. 구조화된 관찰 기록지, 일부만 채워진 모형 틀, 상단의 주장·증거·추론 문장 지원. |

| 심화(다) | 같은 탐구 + R7의 확장 발문. 설명 + 반론 쓰기. |

## differentiation.json 작성 — 과학 매핑

- `shared.subject`: `"과학"`
- `shared.grade`: **영문 학년을 앞에 쓴다** — `"Grade 8 · 중학교 2학년"`,
  `"Grade 4 · 초등학교 4학년"`. 렌더러가 첫 숫자로 학년 밴드(답란 크기)를 잡기 때문이다.
  이 값은 산출물에 출력되지 않는다.
- `shared.standard_code` / `shared.standard_text`: 성취기준 코드와 **원문 그대로**
- `shared.anchor_task`: 앵커 현상
- `shared.t1`..`tN`: 모든 수준이 공유하는 탐구·설명 과제, 키 하나에 과제 하나 —
  `{teacher: "무엇이 어려운지와 볼 것을 평이한 한 문장으로", student: <과제>}` 형태
- `shared.sentence_frames`: 문장 지원을 평문으로, 손글씨 크기의 빈칸과 함께
- 교사 문서: **통합 차별화 수업안**(단계로 조직), 최대 5쪽. 학습지는 각 최대 2쪽
- **저작권:** 검정 교과서·지도서·시중 학습지의 학생 대면 지문을 그대로 옮기지 않는다 —
  탐구 절차 서술, 현상 설명, 발문 모두 해당한다
